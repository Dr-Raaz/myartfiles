B. Billing Root Cause
1. Confirmed Root Cause / Facts (Directly Verified in Workspace & Skill Docs)
1. Personal GCP / Firebase Project Attachment:/firebase-applet-config.json explicitly binds the application to your personal GCP/Firebase project my-art-studio-67 (including its project-specific oAuthClientId, storageBucket, and custom Firestore database ID), instead of an AI Studio-managed Firebase project.
2. Firebase Storage Presence vs. Managed Capabilities: The app still initializes firebase/storage (getStorage(app) in src/services/firebase.ts), declares storageBucket in /firebase-applet-config.json, and contains /storage.rules. Per the firebase-integration-rpc skill, AI Studio's managed Firebase provisioning (ProvisionFirebase) provisions only Firestore Enterprise Edition (Spark free-tier daily quota) and Google Login Auth—it does not provision Firebase Cloud Storage.
3. Unused Gemini Server-Side Capability Flag:/metadata.json still declares "majorCapabilities": ["MAJOR_CAPABILITY_SERVER_SIDE_GEMINI_API"] even though @google/genai and GEMINI_API_KEY are completely unused in code.
2. Strongly Supported Explanation
• Switching from AI Studio's managed Starter Tier to personal project my-art-studio-67 triggered the republish billing gate. When an AI Studio full-stack app is connected to a user-owned GCP/Firebase project (my-art-studio-67), publishing/republishing targets or binds cloud deployment resources under that personal GCP project (Cloud Run / Cloud Build / project billing linkage), which requires an active Google Cloud Billing account on the personal project—unlike AI Studio's managed Starter Tier sandbox.
• On newer Firebase projects, Firebase Cloud Storage (*.firebasestorage.app / /storage.rules) also requires the Blaze plan if provisioned/deployed, though in your live runtime ImageKit is already handling all image storage.
3. Possible Causes Requiring Verification Outside This Container
• Whether GCP project my-art-studio-67 currently has no billing account attached (or billing disabled/suspended).
• Whether your Google AI Studio account (raazprasai1996@gmail.com) has exhausted its free Starter Tier publishing slot/quota (for example, if existing published Cloud Run deployments already consume the free slot).
• Whether MAJOR_CAPABILITY_SERVER_SIDE_GEMINI_API in metadata.json independently triggers a billing check in AI Studio's publisher.
